# YallaKora Web Scraper ⚽️

A robust Python web scraper built with BeautifulSoup and requests to extract daily football match schedules, live scores, teams, and match timings from YallaKora.

## 🚀 Features
- Defensive Programming: Advanced error handling to prevent crashes caused by dynamic or inconsistent HTML structures (NoneType and AttributeError protection).
- Arabic Language Support: Automatically exports scraped data into a utf-8-sig encoded CSV file, ensuring perfect compatibility with Arabic characters in Microsoft Excel.
- Automated Workflow: Fetches and structures daily match data cleanly for quick reporting and analysis.

## 🛠️ Tech Stack
- Python 3.x
- BeautifulSoup4
- Requests
- CSV Module
